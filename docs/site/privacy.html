プライバシーポリシー

最終更新日: 2026年11月23日

MusubiReader（以下「本アプリ」）は、利用者のプライバシーを最大限に尊重し、個人情報を一切収集しないオンデバイス設計を採用しています。本ポリシーでは、本アプリにおけるデータの取り扱いについて説明します。

1. 収集する情報について

本アプリは、氏名、メールアドレス、位置情報、端末識別子（IDFA等）、閲覧履歴、検索履歴などの個人情報を一切収集・送信しません。また、アカウント登録やログインも不要です。

2. 端末内に保存されるデータ

以下のデータはすべてお使いの端末内（ローカルストレージおよび SQLite データベース）にのみ保存され、開発者や第三者のサーバーへ送信されることはありません。

  • 有効化しているプリセットパック・カスタム RSS フィードの設定
  • 取得した記事のメタデータ、既読・未読状態、ブックマーク
  • 注目キーワード・NG ワード・サイトミュート設定
  • Wi-Fi 事前ダウンロードで保存された記事キャッシュ（HTML・画像）
  • 広告ブロック件数の累計およびダウンロード件数設定

キャッシュはアプリ内の「ソース・設定」画面からいつでも削除でき、アプリをアンインストールすることで端末内の全データが削除されます。

3. 外部との通信について

本アプリは以下の目的に限りネットワーク通信を行います。

  • RSS / Atom フィードおよび記事ページの取得: 利用者が購読・閲覧する各Webサイトへ直接アクセスします。各外部サイトにおけるデータの取り扱いは、それぞれのサイトのプライバシーポリシーに従います。
  • プリセットカタログおよび広告ブロックルールの取得: GitHub Pages 上の静的 JSON ファイルを取得するために接続します。この通信に個人を特定する情報は含まれません。

4. 第三者による分析・広告 SDK

本アプリには、アクセス解析ツール（Google Analytics 等）、広告配信 SDK、クラッシュ追跡ツール等の第三者トラッキング SDK を一切組み込んでいません。

5. ローカル通知

利用者が通知を許可した場合、端末内で判定した注目キーワード一致記事についてローカル通知を表示します。プッシュ通知サーバーへのデバイストークン送信は行いません。

6. プライバシーポリシーの変更

本ポリシーの内容は、法令改正や機能追加に応じて予告なく改定することがあります。重要な変更がある場合は本ページ上で告知します。

7. お問い合わせ

本ポリシーに関するご質問は、サポートページまたは GitHub Issues よりお問い合わせください。

Privacy Policy Summary (English)

MusubiReader does not collect, store, or share any personal data. No account is required, and no third-party analytics, tracking, or advertising SDKs are included. All subscriptions, bookmarks, keywords, reading history, and offline article caches remain strictly on your device. Network requests are made directly to the RSS feeds and web pages you choose to read, plus static catalog and content-blocking rule files hosted on GitHub Pages.
