MusubiReader

Wi-Fi 事前ダウンロード・ネイティブ広告ブロック・キーワード通知を備えた、
完全オンデバイス型の高速 RSS リーダーアプリです。

⚡ Wi-Fi ダウンロード

Wi-Fi 接続時に記事の HTML と主要画像を端末内へ事前保存。地下鉄や低速回線でもサクッと開けます。

🛡️ ネイティブ広告ブロック

iOS の WKContentRuleList を活用し、邪魔な広告やトラッカーをOSレベルで軽量にカットします。

🔒 プライバシー最優先

アカウント登録不要・トラッキングゼロ。購読設定やブックマークはすべてお使いの端末内にのみ保存されます。
